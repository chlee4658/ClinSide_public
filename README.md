# ClinSide 성장도표 배포판

이 폴더는 성장도표와 HTML 계산기만 제공하는 독립 배포판입니다. 원본 ClinSide 프로젝트와 별개로 만들어졌습니다.

Windows 사용자는 `clinside.zip`을 압축 해제한 뒤 `clinside.bat`을 실행하세요. Python 설치 여부와 관계없이 실행되도록 Windows 내장 Python 런타임을 포함합니다.

계산기는 `calculators` 폴더에 `.html` 또는 `.htm` 파일을 넣으면 됩니다. 파일의 `<title>`이 메뉴 이름으로 표시됩니다. 계산기별 CSS, JavaScript, 이미지 파일도 해당 폴더에 함께 넣을 수 있습니다.
