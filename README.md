# ClinSide — Windows Portable Downloads

ClinSide is a portable clinical support application for Windows, designed to assist healthcare professionals with everyday clinical workflows.

## Download

Once a verified release has been published, download **ClinSide-Windows-Portable.zip** from the [Releases page](https://github.com/chlee4658/ClinSide_public/releases).

1. Download the ZIP from the latest release's **Assets**.
2. Extract it into a writable folder (for example, `D:\\clinside`).
3. Run `ClinSide-Windows.bat` to start ClinSide.
4. Use the in-app **ClinSide 종료** button to shut down its local server.

No Python installation or administrator rights are intended to be required for the portable distribution.

## Important

- This repository distributes compiled/packaged application files only. The development source is maintained privately.
- **Do not upload** clinic databases, patient information, backups, credentials, API keys, or local configuration files.
- New installations start with an empty local database; records created afterward remain on that computer.
- ClinSide is a clinical support tool, not a substitute for clinical judgment. Verify medication doses and clinical decisions independently.
- Releases should be tested on Windows before publication.
